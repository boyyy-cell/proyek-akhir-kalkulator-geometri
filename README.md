
# Kalkulator Geometri

Program Python sederhana untuk menghitung luas dan keliling bangun datar.

## Fitur
- Persegi
- Persegi panjang
- Segitiga
- Lingkaran
- Validasi input
- Penyimpanan riwayat perhitungan

## Struktur Proyek
```text
├── data/
│   └── nilai_contoh.txt
├── src/
│   ├── main.py
│   ├── analisis.py
│   ├── data_io.py
│   └── utilitas.py
├── tests/
│   └── test_case.md
├── output/
│   └── .gitkeep
├── proposal.md
├── README.md
└── .gitignore
```

## Cara Menjalankan
Pastikan Python sudah terpasang. Jalankan perintah berikut dari folder utama proyek:

```bash
python src/main.py
```

## Cara Menggunakan
1. Jalankan program.
2. Pilih bangun datar pada menu.
3. Masukkan ukuran yang diminta.
4. Lihat hasil luas dan keliling.
5. Periksa riwayat di `output/riwayat.txt`.
6. Pilih menu 5 untuk keluar.

## Pengujian
Rincian pengujian tersedia pada `tests/test_case.md`.
